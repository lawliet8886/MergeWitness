# MergeWitness

Signal Foundry's IBM Bob 2.0 hackathon entry. A developer workflow for finding an interaction failure between two individually green changes, then verifying a repair that preserves both features.

## Provenance

Started during the 25–27 September 2026 event in a separate repository. The earlier `IBMBob2026` repository supplied planning templates and the evidence protocol, not implementation code. All examples use newly authored synthetic data. Dependencies and their licenses will be recorded when selected.

## Evidence boundary

Current status is implementation started; no working prototype or Bob task is claimed by this initial commit. Each completed milestone must include reproducible commands, outputs, and Bob task screenshots where applicable.
