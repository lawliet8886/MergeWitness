# MergeWitness media

- `mergewitness_demo.mp4` is the 100-second H.264/AAC submission video. It is
  assembled from 100 sequential captures of the actual running browser lab:
  execute comparison (00:12), reveal the combined-snapshot witness (00:27),
  select the Bob repair (00:55), and run the repaired candidate in a fresh
  browser worker (01:12). It was decoded successfully with FFmpeg.
- `narration_sulafat.wav` is the English narration synthesized with Google Cloud
  Gemini-TTS voice Sulafat. `narration.txt` is the exact input, and
  `narration_sulafat.json` records the text and audio hashes, duration, model,
  and voice. This narration was generated for the current project.
- `ui-before-run.png`, `ui-results-counterexample.png`, and
  `ui-bob-repair-ran.png` are the corresponding local UI captures.
- `cover.png` is the 1200x630 cover image.
- `cover.png` and the video were uploaded to the LabLab submission draft on
  25 September 2026. Final project publication remains subject to a confirmed
  LabLab submission receipt.
