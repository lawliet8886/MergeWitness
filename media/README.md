# MergeWitness media provenance

`mergewitness_demo.mp4` is the local 150-second, 1920×1080, 30 fps H.264/AAC
replacement judge video, pending a final review and external submission update.
Its SHA-256 is `cb7321dc01a6613b8198fb2826b9fe56df2c8b4ec42ad11474848016796ced7a`
(10,001,374 bytes); a full FFmpeg decode passed. It combines a continuous browser
recording, measured Sulafat narration, sentence-aligned captions, and labeled
screenshots from three genuine IBM Bob IDE tasks. The browser actions include a
fresh four-snapshot comparison, evidence-tab navigation, and a fresh repaired
candidate run. The video identifies the independent audit additions as such;
it does not attribute them to Bob or claim a repair for the second case.
The first comparison action occurred at 1.87 seconds in the recording manifest.

To reproduce it, run the Vite server from `web/`, then run
`python media/capture_live_demo.py`, `python media/align_final_captions.py`, and
`python media/build_continuous_video.py` from the repository root. The raw
browser recording and action manifest stay under ignored `.video-capture/`.
The final narration input, audio and metadata are
`narration_final.txt`, `narration_final_sulafat.wav`, and
`narration_final_sulafat.json`. The narration uses Google Cloud Gemini-TTS
voice Sulafat; the metadata records hashes, duration, model and estimated cost.

The earlier 96-second edit was built from `capture_ui_actions.py`,
`build_final_video.py`, `build_captions.py`, `narration.txt`, and
`narration_sulafat.wav`. Its public URL and SHA-256 are retained as a historical
readback in `submission/LABLAB_SUBMISSION.md`. These scripts and source files
remain for provenance, but the replacement uses the continuous capture above.

`cover.png` is the 1440×810 LabLab poster generated by `build_cover.py`. Its
four cards represent independent snapshot results. The synthetic demonstration
does not claim that one passing probe certifies every merge as safe.
